# Лицензии зависимостей

Фиксация на этапе 0 по документации. Точные версии Python-пакетов — в `pyproject.toml` после установки в venv.

## Приложение (планируемые Python-зависимости)

| Пакет | Лицензия (по документации) | Назначение |
|-------|----------------------------|------------|
| PySide6 | LGPL / коммерческая Qt | UI |
| pytest | MIT | тесты |
| ruff | MIT | линт / формат |

## Внешние CLI (не вендорятся в репозиторий на этапах 0–1)

| Инструмент | Лицензия | Источник |
|------------|----------|----------|
| ipatool | MIT | https://github.com/majd/ipatool |
| libimobiledevice | LGPL-2.1 | https://libimobiledevice.org/ |
| libplist / связанные libs | LGPL / см. upstream | libimobiledevice stack |
| ideviceinstaller | GPL-2.0 | https://github.com/libimobiledevice/ideviceinstaller |

## Замечания

- GPL-2.0 у `ideviceinstaller` влияет на распространение бинарной сборки, если инструмент поставляется вместе с приложением. На этапе 1 инструмент не бандлится: ожидается системный PATH / отдельная установка пользователем.
- Перед упаковкой MVP (этап 6) нужно обновить этот файл фактическими версиями и текстом NOTICE.
