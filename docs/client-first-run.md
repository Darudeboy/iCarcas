# Первое подключение — что сказать клиенту

Краткий путь для человека **без технического бэкграунда**.  
Программа: Windows (ZIP из Releases) или macOS (запуск из исходников / будущая сборка).

## Что понадобится от клиента

1. Компьютер (**Windows или Mac**).
2. iPhone / iPad и **кабель USB**.
3. **Свой** Apple ID (почта) и пароль.
4. Возможность ввести **код из SMS** (или с другого Apple-устройства).
5. На телефоне нажать **«Доверять этому компьютеру»**.

Пароль и ключ сессии остаются на компьютере клиента и никуда не отправляются.

**Дистрибутивы:**
- **Windows:** ZIP `iCarcas-windows.zip` в [iCarcas-exe Releases](https://github.com/Darudeboy/iCarcas-exe/releases) (`iCarcas.exe`).
- **Mac:** DMG / `iCarcas.app` из [iCarcas Releases](https://github.com/Darudeboy/iCarcas/releases) (когда выложен) или сборка по [macos.md](macos.md). Не использовать `.exe` на Mac.

## Шаги в программе

| Шаг | Что сделать |
|-----|-------------|
| A | **Впервые здесь?** → «Установить недостающее» → дождаться OK |
| B | Кабель → разблокировать → «Доверять» → **Телефон… → Найти телефон** (зелёный) |
| C | **Apple ID… → Войти** → почта, пароль, код в отдельном окне (зелёный) |
| D | Найти приложение → **Скачать** → **Установить на устройство** |

Скачивается только то, что уже было на этом Apple ID.

## Windows: окно «Система Windows защитила ваш компьютер»

Это **не вирус**, а SmartScreen: приложение ещё без цифровой подписи издателя.

Скачивать ZIP **только** с [официальных Releases](https://github.com/Darudeboy/iCarcas-exe/releases).

Как запустить один раз:

1. В синем окне нажмите **«Подробнее»** (ссылка).
2. Появится **«Выполнить в любом случае»** — нажмите её.
3. Дальше обычный запуск `iCarcas.exe`.

Не отключайте SmartScreen целиком в настройках Windows — достаточно разрешить этот файл с GitHub.

Долгосрочно для продукта нужна **Authenticode-подпись** (сертификат издателя) — тогда предупреждение почти не появляется.

## Windows vs Mac

- **Windows:** один раз могут понадобиться драйверы Apple — кнопка «Впервые здесь?» ставит их через winget, если можно. Готовый ZIP: [iCarcas-exe Releases](https://github.com/Darudeboy/iCarcas-exe/releases).
- **macOS:** отдельные драйверы не нужны. Утилиты для телефона — через Homebrew (подсказка в «Впервые здесь?»); ipatool программа может скачать сама.

Подробнее для Mac: [macos.md](macos.md).
