# Changelog

## 0.2.0 — 2026-11-20

- Компактная шапка: устройство и сессия App Store в углу (меньше шума сверху).
- История скачиваний/установок и экран успеха установки.
- Оценка лицензии до download по архиву покупок.
- Честный статус фоновой загрузки IPA (прогресс, без ложного «успеха» со старым файлом).
- Убраны иконки приложений из поиска (перегрузка UI / краши).
- Упоминание: УЗ и ключ сессии хранятся только локально.
- Задел под macOS/Linux: интерактивная консоль, локальный ключ без DPAPI, headless download без PowerShell.

## 0.1.0 — 2026-11

- Первый публичный срез: поиск Store ID, download/install, ToS, DPAPI passphrase на Windows, диагностика.
