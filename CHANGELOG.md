# Changelog

## 0.2.0 — 2026-11-20

Утилита **для iOS** (iPhone и iPad). На новом ПК проще понять, что поставить, чтобы устройство нашлось — инструкции укоротили.

### Для нового ПК

- README — четыре шага простым языком: Python → инструменты для телефона → запуск → как пользоваться.
- `docs/setup.md` — короткий чеклист и таблица «что видите → что сделать».
- Вверху одна строка кнопок: **Впервые здесь?** · **Что нового** · **Справка** · **Обучение** · тема (без дубля карточки «Справка» внизу).
- Тексты справки и знакомства — короче, без простыней.
- `check-tools.ps1` проверяет CLI и службу Apple; если чего-то нет — пишет, что скачать.

### Интерфейс

- В углу **«iOS…»**, в подзаголовке iPhone / iPad; кнопка — **«Установить на устройство»**.
- Окно шире: регионы и кнопки справа не обрезаются.
- Шрифт крупнее и читаемее.
- Устройство и сессия App Store в углу — шапка спокойнее.
- **История** скачиваний/установок и экран после успешной установки.
- Перед скачиванием — оценка лицензии по архиву покупок.
- Статус загрузки IPA честный (прогресс и МБ), без ложного «готово» от старого файла.
- Из поиска убраны иконки приложений.
- Напоминание: учётные данные и ключ сессии только на этом компьютере.

### Техническое

- Задел под macOS/Linux: интерактивная консоль, локальный ключ без DPAPI, headless download без PowerShell.

## 0.1.0 — 2026-11

Первый публичный срез: поиск Store ID, скачивание и установка IPA, принятие условий, сохранение passphrase через DPAPI на Windows, диагностика.
