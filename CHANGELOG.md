# Changelog

## 0.2.0 — 2026-11-20

Стало проще понять, что это утилита **для iOS** (iPhone и iPad), и что нужно поставить на новом компьютере, чтобы устройство вообще нашлось.

### Для нового ПК

- В README и `docs/setup.md` расписан первый запуск: Python 3.12+, папка `tools/libimobiledevice` (её нет в git) и на Windows — Apple Mobile Device Support.
- Скрипт `check-tools.ps1` проверяет CLI и службу Apple; если чего-то нет — пишет, откуда взять.
- В шапке блока «Справка» кнопка **«Новый ПК…»** — коротко про эти зависимости, без простыни на главном экране.

### Интерфейс

- В углу кнопка **«iOS…»**, в подзаголовке явно iPhone / iPad; установка — **«Установить на устройство»**.
- Окно шире по умолчанию: регионы и кнопки справа больше не обрезаются.
- Текст крупнее и контрастнее; справка и «Как пользоваться» — обычными фразами, не телеграфным стилем.
- Устройство и сессия App Store сидят в углу — шапка спокойнее.
- Есть **история** скачиваний/установок и понятный экран после успешной установки.
- Перед скачиванием показывается оценка лицензии по архиву покупок.
- Статус загрузки IPA честный: прогресс и МБ, без ложного «готово» от старого файла на диске.
- Из поиска убраны иконки приложений — меньше шума и меньше сбоев UI.
- Напоминание: учётные данные и ключ сессии хранятся только на этом компьютере.

### Техническое

- Задел под macOS/Linux: интерактивная консоль, локальный ключ без DPAPI, headless download без PowerShell.

## 0.1.0 — 2026-11

Первый публичный срез: поиск Store ID, скачивание и установка IPA, принятие условий, сохранение passphrase через DPAPI на Windows, диагностика.
